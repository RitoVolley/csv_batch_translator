・APIキーは.envで管理し、GitHub上には機密情報を含めない設計としています。
・DeepLのAPIキーの取得手順
　1. 以下のサイトを開く。
　　https://www.deepl.com/pro-api
　2. 画面右上の「ログイン」ボタンをクリックし、DeepLアカウントにログインする。
　3. ログイン後、画面右上のアカウントアイコンをクリックし、「アカウント」を選択する。
　4. 「APIキーと制限」タグに移動し、APIキーを確認する。
　5. 【「APIキーと制限」タグが表示されていない場合】
　　　画面右上の「Start free trial」から「API Free」プランを選択
　　　※API Pro版にグレードアップしなければ、支払いは発生しません。
　5. 【APIキーが生成されていない場合】
　　　新しいAPIキーを生成する。
　6. APIキーをコピーする。
